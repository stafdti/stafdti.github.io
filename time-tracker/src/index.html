How Time Tracker works
  1. Add topics. Type a free-text name (e.g. "Email", "Deep Work") in the field below the chart and click Add topic. Topics appear as boxes, sorted alphabetically.
  2. Start tracking. Click a topic box to start its stopwatch. The box turns green with a pulsing dot and shows a live elapsed timer.
  3. Switch topics. Click a different topic box to automatically stop the current one and start the new one — no separate "stop" step needed.
  4. Stop tracking. Click the currently running topic again to stop it without starting anything new.
  5. Delete a topic. Hover a box and click the "×" in the corner. Already tracked time for that topic is kept in the history and chart.
  6. Weekly chart. The stacked bar chart at the top shows the current Monday–Friday week, with one colored segment per topic per day. A striped segment marks the time that's still running.
  7. Export / Import. Use Export data to download all topics and tracked time as a JSON file, and Import data to restore it later (or on another device/browser) — importing replaces all current data after confirmation.
  8. Dark / light mode. Use the moon/sun button to switch themes. Your preference is remembered for next time.

Everything is stored only in this browser's local storage — there is no server or account involved.
