# AI-Generated Mini Apps

This repository is a collection of small, browser-based applications generated with the help of AI. Each mini app lives in its own folder, has its own README, and can generally be run independently as a static web app.

## Table of contents

- [Block Cascade](#block-cascade)
- [Drum Pad Machine](#drum-pad-machine)
- [Finance Planner](#finance-planner)
- [Time Tracker](#time-tracker)

## Projects

### Block Cascade

A retro-styled arcade puzzle where you arrange falling polyomino pieces to clear rows. Includes keyboard and touch controls, synthesized sound effects, selectable themes, and a saved best score.

[Read the Block Cascade README](block-cascade/README.md)

### Drum Pad Machine

A 16-pad drum machine and step sequencer with configurable tempo, recording, manual pattern editing, and browser-based persistence.

[Read the Drum Pad Machine README](drum-pad-machine/README.md)

### Finance Planner

A browser-based dashboard for exploring personal finance and brokerage transaction CSVs. It provides filters, summary metrics, visualizations, and a searchable transaction table.

[Read the Finance Planner README](finance-planner/README.md)

### Time Tracker

A browser-based activity timer for tracking time by topic. It includes a weekly chart, data import/export, local persistence, and installable PWA support.

[Read the Time Tracker README](time-tracker/README.md)
