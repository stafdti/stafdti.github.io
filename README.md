# AI-Generated Mini Apps

This repository is a collection of small, browser-based applications generated with the help of AI. Each mini app lives in its own folder, has its own README, and can generally be run independently as a static web app.

## Projects

### Meteroite

A self-contained neon orbital arcade game built with plain HTML, CSS, and JavaScript. Pilot a scout ship, dodge pink debris, collect energy orbs, fire pulse shots, and survive increasingly active waves with browser-generated Web Audio effects.

[Open Meteroite](meteroite/index.html) · [Read the Meteroite README](meteroite/README.md)

### Block Cascade

A retro-styled arcade puzzle where you arrange falling polyomino pieces to clear rows. Includes keyboard and touch controls, synthesized sound effects, selectable themes, and a saved best score.

[Read the Block Cascade README](block-cascade/README.md)

### Drum Pad Machine

A 16-pad drum machine and step sequencer with configurable tempo, recording, manual pattern editing, and browser-based persistence.

[Read the Drum Pad Machine README](drum-pad-machine/README.md)

### Finance Planner

A browser-based dashboard for exploring personal finance and brokerage transaction CSVs. It provides filters, summary metrics, visualizations, and a searchable transaction table.

[Read the Finance Planner README](finance-planner/README.md)

### Parrondo Portfolio Lab

A browser-based historical portfolio backtester that compares strategies for two uploaded stock price series. It supports regional CSV files, cumulative euro values, periodic 50/50 rebalancing, momentum, alternating allocation, and strategy comparison.

[Read the Parrondo Portfolio Lab README](parrondo paradox/README.md)

### RetroOS 1984

A browser-based retro workstation simulation with draggable application windows, CRT effects, selectable monitor themes, synthesized audio, a text editor, pixel painter, calculator, synthesizer, space game, and system control panel.

[Read the RetroOS README](retro-os/README.md)

### Time Tracker

A browser-based activity timer for tracking time by topic. It includes a weekly chart, data import/export, local persistence, and installable PWA support.

[Read the Time Tracker README](time-tracker/README.md)

### ByteWave Synthesizer

A retro-styled standalone Web Audio synthesizer with configurable oscillator, filter, envelope, polyphonic keyboard playback, and immediate local patch persistence.

[Open the ByteWave Synthesizer](synthesizer/index.html) · [Read the Synthesizer README](synthesizer/README.md)
