04 / making sound

Two instruments, two different workflows

▦

Drum Pad Machine

  • 16 pads in a 4 × 4 grid
  • 16-track sequencer with 16 steps
  • Configurable 40–300 BPM tempo
  • Playhead, record mode, manual editing
  • Pattern, BPM, and pad assignment persist locally

Input: 1 2 3 4 / Q W E R / A S D F / Z X C V

∿

ByteWave Synthesizer

  • Oscillator, filter, envelope, and polyphony
  • Live output activity meter and panic button
  • Immediate patch persistence via localStorage
  • Responsive touch-friendly piano keyboard
  • Language-aware QWERTY / QWERTZ mapping

Audio: one Web Audio voice graph per active note

The browser is not just a canvas — it is an instrument.Both projects use native audio capabilities without shipping audio processing frameworks.

07 / time tracker

A stopwatch that remembers everything

Time Tracker is a zero-setup, single-page activity timer. Clicking a topic starts it; clicking another switches immediately.

08 / the data model

Small schema, useful guarantees

Topic

id · stable identity
name · trimmed, case-insensitively unique
createdAt · ISO timestamp

TimeEntry

topicId + denormalized topicName
startIso · endIso · minutes
date · local start date for charting

ActiveState

Either null or the currently running topic and its startIso. Persisted so a reload never silently loses an active session.

Export bundle

One JSON file containing version, exportedAt, topics, entries, and active state. Import validates before replacing local data.

localStorage keys: timeTracker.topics · timeTracker.entries · timeTracker.active

09 / platform strategy

Static does not mean limited

Native browser APIs

Canvas 2D, Web Audio, localStorage, FileReader, Blob downloads, Pointer Events, and service workers.

Progressive enhancement

Keyboard controls where available, touch controls on small screens, and responsive layouts instead of separate apps.

Offline by design

Several projects work directly from file://; PWA projects add manifests, caching, and installable app shells.

External assets

Some projects load Bootstrap, Tailwind, fonts, or Chart.js from CDNs. Those visual assets may need a network connection.

Self-contained logic

Application behavior remains in plain HTML, CSS, and JavaScript with no required build tooling or package installation.

10 / architecture in one view

One recurring loop: input → state → render

Keyboard / touch / file→Browser event→In-memory state→localStorage / Web Audio→DOM / Canvas render

Games

Game loop updates positions, collisions, score, and difficulty; Canvas reflects the current frame.

Creative tools

User gestures trigger audio or mutate patterns; controls and visual indicators mirror the state.

Dashboards

Files become normalized records; filters and aggregations produce charts and tables.

The common architecture is deliberately small enough to inspect, modify, and run without a toolchain.

12 / responsible reuse

Small experiments, clear boundaries

Audio and assets

The drum machine intentionally does not ship sample files. Users are directed toward royalty-free or public-domain sources and must provide the 16 files themselves.

Browser privacy model

Personal finance and time-tracking data is processed locally. Export and import are explicit user actions rather than hidden uploads.

Project-specific notes

Individual READMEs may add their own licensing or originality statements. Check each project and its source files before redistribution.
